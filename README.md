# Quay Installer

Direct, versioned Microsoft Store installer files for [Quay](https://github.com/dhhieu113pro/quay).

Files are published automatically from Quay release tags.

## Layout

```text
v0.1.5/
  Quay_0.1.5_x64_en-US.msi
  Quay_0.1.5_arm64_en-US.msi
```

Microsoft Store package URLs use `raw.githubusercontent.com`, for example:

```text
https://raw.githubusercontent.com/dhhieu113pro/quay-installer/main/v0.1.5/Quay_0.1.5_x64_en-US.msi
```
